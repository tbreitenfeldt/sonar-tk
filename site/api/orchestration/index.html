    BuiltMapGridGame dataclass

    Represents a fully wired map + grid game composition.

    Attributes:

    Name Type Description
    window Window

    Top-level application window.
    screen ContainerScreen

    Container screen that hosts the grid.
    map2d Map2d

    Loaded game map with character state.
    grid Grid[MapTile]

    Grid view over map tiles.

    MapGridGameBuilder

    Bases: Generic[T]

    Builds a map-driven grid game with minimal setup boilerplate.

    This builder is additive and optional. It composes existing APIs (Window, ContainerScreen, Grid, and load_2d_map) and still returns underlying objects for advanced customization.

    map2d property

    Get the configured map.

    Raises:

    Type Description
    ValueError

    If no map has been configured yet.

    with_map(map_name, file_name, parser, tile_mapper, character)

    Load and attach map data for the grid game.

    with_loaded_map(map2d)

    Attach an already-loaded map instance.

    with_grid_options(label='', speak_coordinates_on_change=False, speak_value_on_change=False, arrow_key_repeat_interval=0.25)

    Customize grid behavior without manual grid construction.

    on_navigation(handler)

    Register an on_navigation handler for the built grid.

    on_border(handler)

    Register an on_border handler for the built grid.

    build()

    Create and wire all components.

    Raises:

    Type Description
    ValueError

    If no map has been provided.
    RuntimeError

    If builder keys already exist in target state machines.

    MapSoundNavigationController

    Handle map navigation and border sounds for grid-based maps.

    The controller is intentionally injectable so callers can swap sound services, position mapping, or handler wiring strategy without changing core behavior.

    on_navigation(grid, direction)

    Play movement/wall sounds and update map state.

    Returns True when the event should be handled (blocked movement), and False when grid navigation should continue.

    on_border(grid, direction)

    Play a border collision sound.

    Returns True if a wall sound mapping exists and was played.

    play_wall_sound(grid, direction)

    Play the wall collision sound from the next tile position.

    MapObjectCollectionSession

    Bases: Generic[TMapObject]

    Manage spawned map objects for pickup/collection game loops.

    The session owns the lifecycle for objects it spawns and supports type-safe collection, configurable spawn filtering, and transactional resets.

    collected_count property

    Return how many objects were collected in the current session.

    remaining_count property

    Return how many spawned objects remain on the map.

    reset()

    Respawn session objects using current spawn constraints.

    Reset is transactional. If object creation or registration fails, the previous active set is restored and no partial spawn remains.

    has_object_at(coordinates)

    Return whether a matching object exists at coordinates.

    collect_at(coordinates)

    Remove and return the matching object at coordinates, if present.

    MessageActionState

    Bases: State

    Reusable state that speaks a message and waits for action keys.

    SceneAudioState

    Bases: State

    Reusable scene state that gates progression on audio completion or skip input.

    bind_volume_hotkeys(window, *, sfx_player=None, music_step=0.05, sfx_step=0.05, couple_music_to_sfx_ratio=None)

    Bind default hotkeys for runtime music and sfx volume control.

    F7/F6 adjusts music, while Shift+F7/Shift+F6 adjusts sfx.
