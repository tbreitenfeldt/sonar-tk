    map_builder

    sonartk.map_builder

    Map2d

    character_index property

    Read-only coordinate index for registered characters.

    object_index property

    Read-only coordinate index for registered map objects.

    add_row(row)

    Insert a map row and update map dimensions.

    New rows are prepended so y=0 points at the most recently inserted row, matching the current map coordinate convention.

    get_tile(coordinates)

    Return the tile at coordinates, raising on out-of-range access.

    set_tile(coordinates, tile)

    Replace the tile at coordinates, raising on out-of-range access.

    set_tiles(updates)

    Apply multiple tile replacements as a single convenience operation.

    register_character(character)

    Register a character and return any displaced occupant at that coordinate.

    move_character(character, new_coordinates)

    Move a character and return any displaced occupant at destination.

    remove_character(character)

    Remove a registered character from the coordinate index.

    register_map_object(map_object)

    Register a map object and return any displaced occupant at that coordinate.

    move_map_object(map_object, new_coordinates)

    Move a map object and return any displaced occupant at destination.

    remove_map_object(map_object)

    Remove a registered map object from the coordinate index.

    find_map_object_coordinates(map_object)

    Return coordinates for a registered map object by identity.

    is_map_object_registered(map_object)

    Return whether a map object is currently registered by identity.

    get_map_object_at(coordinates)

    Return the registered map object at coordinates, if present.

    remove_map_object_at(coordinates)

    Remove and return the map object at coordinates, if present.

    Map2dQueries

    Spatial query and pathfinding operations for a Map2d instance.

    invalidate_path_cache()

    Invalidate all cached pathfinding results.

    iter_radius_hits(starting_coordinates, tile_names=None)

    Yield query hits around a starting point for distances 1..radius-1.

    get_coordinate_hit(coordinates, tile_names=None)

    Return a typed query hit for coordinates, or None if out-of-range.

    find_path(start, end, state=None)

    Find and return the lowest-cost passable coordinate path between points.

    find_path_result(start, end, state=None)

    Find a path and return path + diagnostic metadata.

    get_adjacent_passable_coordinates(coordinates, state=None, end=None)

    Return cardinally adjacent coordinates that are passable.

    is_tile_passable(coordinates, state=None, end=None, from_coordinates=None, move_direction=None)

    Return whether a tile can currently be traversed.

    is_coordinates_in_range(coordinates)

    Return whether coordinates are within map bounds.

    MapQueryResult dataclass

    Typed result for a coordinate-level spatial query.

    PathfindingResult dataclass

    Structured result metadata for a pathfinding search.

    PathfindingState dataclass

    Optional runtime rules that affect pathfinding passability.

    with_overrides(**overrides)

    Return a copy of this state with selected fields overridden.

    register_profile(name, state, *, overwrite=False) classmethod

    Register a named custom profile for reuse across pathfinding calls.

    from_profile(name) classmethod

    Return a previously registered custom profile by name.

    unregister_profile(name) classmethod

    Remove a named custom profile if it exists.

    list_profiles() classmethod

    Return all registered custom profile names sorted alphabetically.

    export_profiles() classmethod

    Export registered profiles as JSON-safe dictionaries.

    import_profiles(profiles, *, overwrite=False, strict=True) classmethod

    Import profile dictionaries produced by export_profiles.

    save_profiles(file_path, *, pretty=True, sort_keys=True) classmethod

    Write registered profiles to a JSON file.

    load_profiles(file_path, *, overwrite=False, strict=True) classmethod

    Load and register profiles from a JSON file.

    to_profile_dict()

    Serialize this state to a JSON-safe dictionary.

    Callable fields are intentionally unsupported for persistence.

    from_profile_dict(payload, *, strict=True) classmethod

    Deserialize a profile dictionary into PathfindingState.

    for_player(tier='standard') classmethod

    Profile for player-style movement with selectable strictness tier.

    for_flying_enemy(tier='standard') classmethod

    Profile for flying enemies with selectable strictness tier.

    for_heavy_unit(tier='standard') classmethod

    Profile for heavy units with selectable strictness tier.
